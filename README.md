# fetchuri

Fetch digests and uri fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/fetchuri/

## Install / run

```bash
git clone https://github.com/theworker02/fetchuri.git
cd fetchuri
node src/cli.js
node --test
```
